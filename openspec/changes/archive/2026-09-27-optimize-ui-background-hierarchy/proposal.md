# Proposal

## Why

当前整体背景色过深，三个主要区域（标题栏、侧边栏、主内容区）之间缺乏清晰的视觉层次：标题栏和侧边栏共用 `--sidebar-bg`（`#080c12`）完全无差异，主内容区 `--surface-0`（`#0d1219`）与侧边栏色差极小，用户感知上整个界面"糊成一片"。需要适度提亮背景色并建立三层分明的色调层次，让导航区、功能区、内容区一目了然。

## What Changes

- **提亮基底色值**：在保持深色主题基调的前提下，将所有 surface 变量整体提亮约 15–20%，使界面不再沉闷压抑
- **分离标题栏与侧边栏背景**：标题栏使用独立的更深色变量（保留"窗口框架"感），侧边栏使用中间色（导航容器），主内容区使用最浅色（内容承载区）
- **新增独立 CSS 变量**：拆分 `--sidebar-bg` 为 `--titlebar-bg` 和 `--sidebar-bg` 两个变量，消除共用导致的层次缺失
- **适配派生变量**：同步调整 `--surface-1`/`--surface-2`/`--surface-3`、`--border` 等关联色值，确保卡片、输入框、边框等元素在新基底上对比度仍然舒适
