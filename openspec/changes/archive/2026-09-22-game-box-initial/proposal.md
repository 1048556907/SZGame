# Proposal

## Why

用户本地有大量游戏与应用程序，散落在桌面、开始菜单和各个安装目录中，缺少一个统一的管理入口。需要一款桌面盒子应用，将任意可执行程序（.exe、.bat、URL）以卡片形式组织，按分组归类，一键启动。这是项目的初设版本，建立游戏盒子、分组管理、设置三大核心能力的基础。

## What Changes

- 新增游戏盒子主界面，以卡片网格形式展示全部已添加的游戏/程序
- 支持添加任意可启动项：.exe 文件、.bat 脚本、URL 链接，每项可配置启动参数与封面图
- 新增分组管理：左侧分组导航栏，支持新建/重命名/删除分组，游戏单选归属
- 卡片与分组均支持拖拽排序，卡片在分组内独立排序
- 新增搜索功能：按游戏名称实时搜索，搜索结果跨分组聚合展示
- 新增卡片详情页：侧边抽屉形态，包含封面点击放大预览、编辑、删除、启动
- 新增应用设置：最小化行为（托盘/任务栏）、关闭按钮行为（退出/最小化到托盘）、版本号展示
- 应用使用系统托盘图标，设置最小化/关闭行为后生效
- 视觉风格：深色主题 + 蓝色点缀，简约克制

## Capabilities

### New Capabilities

- `game-box`: 游戏盒子核心能力——卡片展示、启动执行、搜索、拖拽排序、详情抽屉、封面上传与预览
- `group-management`: 分组管理能力——分组的 CRUD、游戏的单分组归属、分组与卡片的拖拽排序
- `settings`: 应用设置能力——窗口最小化行为、关闭按钮行为、系统托盘集成、版本号展示

### Modified Capabilities

（空项目，无既有 capability）

## Impact

- 新增 Electron 主进程与渲染进程完整应用骨架
- 引入 SQLite 本地数据库（embedded），主进程独占读写
- 引入系统托盘、窗口管理、文件对话框等 Electron API
- 依赖 React 18 + TypeScript + Vite + Electron
- 数据库文件与封面图文件存放在操作系统用户数据目录下（跨平台兼容）
